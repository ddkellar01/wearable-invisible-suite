# Hardware Schematics & Wiring Diagrams

This directory contains electrical schematics, pinout diagrams, and power distribution layouts for the active camouflage suit.

## Key Components
- **NVIDIA Jetson Orin Nano Carrier Board**: Central edge AI compute node.
- **MIPI DSI / SPI Bus**: High-speed interface to flexible micro-OLED panels.
- **Li-Po Power Rails**: Dual 12V regulated lines with integrated current sensing telemetry.
